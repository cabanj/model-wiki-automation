Mixture of Agents — Free-Tier Setup Guide

Updated 2026-08-22

How to wire up a free MoA pipeline using only $0 API calls, configured for Hermes.

Current preset: default

Configured in config.yaml via moa.presets.default:

moa:
  presets:
    default:
      reference_models:
        - provider: nous
          model: tencent/hy3:free
          role: 
        - provider: opencode-zen
          model: laguna-s-2.1-free
          role: 
        - provider: opencode-zen
          model: deepseek-v4-flash-free
          role: 
      aggregator:
        provider: opencode-zen
        model: nemotron-3-ultra-free
      reference_max_tokens: 600

How it works

  1. Each reference model independently analyzes the prompt and produces a response
  2. Responses are aggregated (synthesized) by the aggregator model
  3. The aggregator produces a final, higher-quality output

Reference max tokens: 600 per response (before aggregation)

Cost analysis (all free)

2 reference models × ~$0.00 + 1 aggregator × ~$0.00 = $0.00 total per request

Even though some OR models show micro-pricing ($0.0000003/1M),
these are well within the free tier budgets of both Nous Portal and OpenRouter.
