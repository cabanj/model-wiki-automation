## Why this exists

"Free" in the LLM API world is badly underspecified. A model tagged free on an aggregator may be rate-limited to unusable levels, may require a payment method, or may disappear without notice. This roster is built on one rule — **a model is listed only if its live metadata says the price is exactly zero** — and every row shows which source confirmed it, so you can cross-check.
